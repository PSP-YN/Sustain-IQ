# Security policy

This repository currently serves a public event-information website and does not intentionally collect or store participant personal data.

## Reporting

Do not publish exploit details in public issues. Report suspected vulnerabilities privately to the repository owner through GitHub private vulnerability reporting, if enabled.

## Scope

Relevant reports include cross-site scripting, dependency vulnerabilities with an exploitable path, unsafe external links, exposed credentials and deployment misconfiguration.

Do not commit API keys, access tokens, passwords, participant personal information or private organiser documents. Rotate any credential that is accidentally exposed.
