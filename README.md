# SUSTAINIQ 2026 — Official Hackathon Website

The public event website for SUSTAINIQ 2026, hosted by the Civil Department Association at Vidyavardhaka College of Engineering (VVCE), Mysuru, Karnataka, India.

**Production:** https://sustain-iq-ivc.vercel.app/
**Repository:** https://github.com/PSP-YN/Sustain-IQ

## Event at a glance

| Detail | Published information |
|---|---|
| Event | SUSTAINIQ 2026 — Build. Solve. Sustain. |
| Dates | 3–4 December 2026 |
| Format | 24-hour, in-person student hackathon |
| Venue | Sports Complex, VVCE, Mysuru, Karnataka, India |
| Team size | 3–4 students |
| Planned capacity | 80 teams (40 from Karnataka, 40 from outside Karnataka) |
| Team registration | ₹999 per team (as listed in the event brochure) |
| Prize pool | ₹75,000+ (subject to sponsorship updates) |
| Food | Provided during the event |
| Accommodation | Not provided |

Four challenge domains are planned; official domain names are not yet published. Before the event, teams choose a topic/problem and submit a preliminary PPT using the organiser template. During the onsite event, teams select an official problem statement and build for 24 hours.

## Experience and interaction

- A persistent, full-viewport recorded Minecraft gameplay video sits behind the complete long-form page.
- Page scroll position scrubs the video timeline: scrolling down advances the footage and scrolling up reverses it, keeping the world journey tied to the page rather than running independently.
- The background is the supplied `Minecraft_player_exploring_world_3723f312_1080p.mp4`, optimized as `public/minecraft/videos/world-journey.mp4` for browser delivery.
- The video is muted, has no audio track in the optimized copy, and uses a static gameplay poster while the video initializes.
- Responsive glass UI, high-contrast typography, keyboard-friendly anchor navigation and reduced-motion CSS support.

The procedural Three.js player, companion and Herobrine scene is no longer rendered. The moving characters, camera and environment visible in the background come from the supplied recorded video; this remains a website presentation, not an interactive Minecraft game session.

The source clip is 1,920×1,080 at 24 fps and approximately 14.93 seconds. The optimized web copy is H.264 MP4 at 1,920×1,080, 24 fps, with audio removed and fast-start metadata for progressive browser loading. It is not 4K footage.

## SEO, AEO and local discovery

- Canonical metadata, descriptive title/description, keywords, Open Graph and Twitter card metadata.
- `robots.txt` and `sitemap.xml` generated by Next.js metadata route conventions.
- Semantic page sections, one primary page H1, clear event facts and answer-first FAQ content.
- JSON-LD for `WebSite`, `Event` and `FAQPage`.
- Local discovery signals for Mysuru, Karnataka, India (`en-IN`, `IN-KA`) and a complete venue postal-address structure.
- Event information is intentionally conservative: unknown dates, platform links, domains and schedules are not fabricated.

SEO/AEO/GEO implementation improves machine readability; search ranking, rich-result eligibility and inclusion in AI answers are not guaranteed. Validate structured data with Google's Rich Results Test and Search Console after release.

Set `NEXT_PUBLIC_SITE_URL` to the canonical origin if deploying to a different domain. The default is the production URL above.
