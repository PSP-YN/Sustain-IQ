# Contributing

1. Fork the repository and create a focused branch from main.
2. Install dependencies with npm install.
3. Run the development server using npm run dev.
4. Keep event facts grounded in organiser-approved material. Do not invent registration links, domains, deadlines or schedules.
5. Preserve responsive layouts, semantic headings, keyboard navigation and reduced-motion support.
6. Run npm run lint, npx tsc --noEmit and npm run build before opening a pull request.
7. Document third-party asset sources and licenses in docs/ASSETS.md.

Use clear commit messages and include screenshots or a short screen recording for visual changes.
